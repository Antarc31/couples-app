## Mantieni aggiornato docs/CLAUDE_PROJECT_KNOWLEDGE.md

`docs/CLAUDE_PROJECT_KNOWLEDGE.md` è un brief compatto che l'utente carica
come "Project knowledge" in un Project su claude.ai (pubblico senza
accesso al repo). Quando in una sessione emergono decisioni prodotto
nuove, feature completate, o lezioni tecniche importanti (es. un bug
class che si ripete, una nuova regola di workflow), aggiorna quel file
nello stesso giro di lavoro — non aspettare che l'utente lo richieda
esplicitamente una seconda volta. Non è sincronizzato automaticamente:
l'utente deve ri-caricare il file a mano sul suo Project, quindi tienilo
sempre pronto e accurato.
